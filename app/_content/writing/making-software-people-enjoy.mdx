# Making Software People Enjoy Using

Understanding the technical side of software opens up more possibilities for what can be built. But that is only part of the job.

I also care about what happens when another person actually uses the thing. Good ideas can become frustrating software when the interface gets in the way, while a technically modest tool can become genuinely useful when the experience is clear and enjoyable.

For me, the interesting part is bringing those two sides together: understanding how the system works and caring about how it feels to use.
